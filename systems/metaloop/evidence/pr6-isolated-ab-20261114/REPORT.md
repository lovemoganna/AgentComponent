## 缺陷与修复记录

1. **原升级门禁漏洞已修复。** 开发题改 ID/换序不能再绕过内容指纹，held-out 内部重复也会被拒绝。原 46 项及 5 项新回归在本地和 [GitHub CI](https://github.com/lovemoganna/AgentComponent/actions/runs/43566071711) 共 51/51 通过。本轮没有改变该代码、Prompt 或 Registry。
2. **运行时故障已绕开到正常配置路径。** 原生配置目录只读导致启动失败；项目说明发现还会触发环境不支持的嵌套 bwrap。改用每进程临时原生运行时目录、关闭项目说明读取和工作工具后成功。未修改原登录、全局配置或系统挂载，未关闭宿主环境防护。预检错误及诊断在 `preflight/`。
3. **评测包装器有两处错误，已纠正。** 初始安全导入白名单漏了契约允许的 `solution` 模块，runpy 包装器又将路径参数传给 unittest。修正只涉及测试加载方式，没有改预期答案、通过标准或模型产物。初始验证器、失败日志、修复 diff 和前后哈希全部保留；两版统一用修正后的同一验证器执行。该失败不计为模型缺陷。
4. **未观察到 Prompt 关键退化，也未观察到质量提升。** 两个领域的固定任务均通过，不足以验证 Candidate 的跨任务编排能力；更不能用字符数更少替代质量证据。

## 决策

**保留 Stable；Candidate 不晋升；PR #6 不合并。** 保留已验证的门禁修复和本轮所有原始证据。下一次升级评测应由独立评审封存新任务，并覆盖真实工具工作流、失败恢复和跨任务迁移；若要声称成本更优，应取得可核对的金额或预先约定的 token 成本口径。

这不是继续修改提示词的依据：本轮没有发现需要改 Prompt 的实质缺陷。
