# 用途

用接近 ASD-STE100 的受控表达约束，把复杂内容改写成短、清楚、易理解的说明。

# Prompt

请用 **80% ASD-STE100 风格**解释下面的内容。

要求：

- 短句。
- 一句只表达一个主要意思。
- 优先使用常用词和主动语态。
- 删除空话、套话、重复和模糊表达。
- 复杂内容拆成明确步骤。
- 保留必要专业术语，但首次出现时用白话解释。

目标：**让没有背景知识的人快速看懂，而不是把内容写得更专业。**

内容：
【输入内容】

# 使用条件

- 适合解释复杂概念、专业材料、技术说明和业务规则。
- 输入应包含待解释的原始内容。
- “80% ASD-STE100”表示借用其清晰写作约束，不要求逐条满足完整规范。
