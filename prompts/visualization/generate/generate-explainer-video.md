# 用途

把任意主题拆成可执行的可视化讲解视频方案，使画面承担解释功能，而不是只做 PPT 式展示。

# Prompt

把下面的主题设计成一个**短篇可视化讲解视频**。

参考 3Blue1Brown 的原则：通过动态图形逐步解释概念，而不是单纯播放 PPT。

要求：

- 先确定一个核心问题。
- 按「问题 → 直觉 → 机制 → 示例 → 结论」展开。
- 每个镜头只解释一个知识点。
- 旁白和画面必须同步。
- 抽象概念优先转成动态图形。
- 删除与理解无关的视觉效果。
- 输出完整分镜、旁白、画面动作和实现方案。

主题：
【输入主题】

# 使用条件

- 适合需要通过动态过程、空间关系或逐步推演来解释的主题。
- 输入至少需要一个明确主题。
- 默认生成视频方案和实现设计；是否实际渲染视频取决于执行环境是否具备相应工具。
